VIGIL — Privacy Policy

Effective: 2026-08-12

VIGIL is a Chrome extension that watches pages you choose — a cinema seat map, a product page, a resale listing — and tells you when something on it changes. This page describes what data it touches and where it goes.

There is no server

VIGIL has no backend. Nothing you watch, nothing it captures, and nothing it stores is ever sent to us or to any server we operate, because none exists. Everything below happens entirely inside your own browser, using chrome.storage.local — storage private to your device and your Chrome profile.

What it accesses, and when

  • Nothing, by default. VIGIL requests no site access at install. It requests access to a specific site only when you choose to record a watch on that site, using Chrome's own per-site permission prompt.
  • While recording, it observes the network requests the page you're on makes to itself (its own fetch/XHR calls) — never requests to other sites, and it never blocks, delays, or modifies anything the page does.
  • While a watch is armed, it periodically re-issues the one specific request you captured, to check whether the result has changed, using your existing logged-in session on that site.

Cookies

VIGIL never stores your cookies. It replays a captured request with credentials: 'include', which means Chrome itself attaches whatever cookies are already in your browser's own cookie jar at the moment of the request — VIGIL never reads, copies, or persists them anywhere.

What's stored on your device

  • Your configured watches (which site, which rule, how often)
  • The last-seen state of each watch, so it can tell you what changed
  • A short rolling price history, used only to detect a genuine price drop rather than daily noise
  • A log of past alerts, capped in size

None of this leaves your device. Uninstalling the extension removes all of it.

If you export or contribute a template

VIGIL can export the "shape" of a site's request — which endpoint, which fields — so other users don't have to record it themselves. Before that file is created, VIGIL strips anything that could identify you: bearer tokens, API keys, and any session, order, customer, cart, or user identifier in the URL or headers. You choose whether to share that file; VIGIL never does this automatically.

The shared template feed

To pre-fill setup for popular sites, VIGIL periodically fetches a small public JSON file listing known site request-shapes, hosted at dotzak25.github.io/vigil. This fetch contains no information about you or what you're watching — it's a plain, anonymous request for a static catalogue file, the same for every user.

What VIGIL does not do

  • No analytics, telemetry, or tracking of any kind
  • No advertising, and no data sold or shared with any third party
  • No automated purchasing — VIGIL watches and notifies, it never buys anything or acts on your behalf
  • No accounts — there is nothing to sign up for

Permissions, plainly

  • storage — save your watches and settings on-device
  • alarms — schedule the periodic checks
  • notifications — show you an alert when something changes
  • tabs — list open tabs so you can pick one to record, and open a result you click on
  • scripting, plus a per-site host permission you grant explicitly — inject the observer that watches a recorded page's own network requests, only on sites you've said yes to
  • offscreen — play a short alert tone

Changes
